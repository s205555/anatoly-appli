## Fichiers

- `art/<clé>.txt` : fichiers d'origine de GymMane, copiés sans aucune modification (une ligne par image de l'animation, données de tracé SVG).
- `<clé>.svg` : les mêmes tracés emballés dans un fichier SVG (remplissage pair-impair, couleur du texte), sans autre modification.
